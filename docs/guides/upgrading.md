## Preserve the 1.x records

The current solo JSON export is format 1; changes added options and native table access without changing existing seeded deals. Keep language, hand, level, length, double set, diagonals and seed with progress. This documentation rollout changes comments, examples and navigation without changing emitted SDK behavior or dictionaries.

## Moving from score-based tile boards

Kumimoji is a race to use a bag in a connected accepted crossword, with solo and shared-bag rules. It does not inherit another game's scoring, premium squares or dictionary choices. Map external tile faces through the native language functions and use native judging and inventory validation.

## Check an upgrade

Round-trip representative solo/party saves, compare seeded bags, test wild identities and both language loaders, and verify ready/error handling in hosts. Preserve the shipped attribution and notices. [CHANGELOG.md](../../CHANGELOG.md), [NOTICE.md](../../NOTICE.md) and [the embed contract](../embeds.md) record compatibility and data terms.
